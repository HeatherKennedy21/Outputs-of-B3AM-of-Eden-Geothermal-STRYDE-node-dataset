# Outputs-of-B3AM-of-Eden-Geothermal-STRYDE-node-dataset
Three-component beamforming output data using the toolbox B3AM, analysing the three-component STRYDE node dataset collected at the Eden Geothermal site in St Austell, Cornwall, UK (Hudson, et al., 2024). This is the data that was used in the analysis for the paper titled "Three-component beamforming of surface waves complements body wave anisotropy from shear wave splitting" submitted to Geophysical Journal International (currently under review). 

The data is in .mat format, from the MATLAB version of the B3AM code. The data, the beamformer output, is organised into .zip folders each name representing a day of data (written in day numbers for 2022, e.g. 324 corresponds to the 10th of Novermber 2022). Each day folder has 15 files, each for a given frequency denoted as fx.xxx (e.g. f0.600 is a frequency of 0.6 Hz) and EN represents the assigned network code.
